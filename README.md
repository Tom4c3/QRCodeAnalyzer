# QRコード解析

画像をまとめて放り込むと、**画像名とQRコードの中身の対応**を一覧にするツールです。URLはそのままクリックで開けます。
行を選ぶと、**シンボルのどの領域に何が書かれているか**を色分けで確認できます。

すべてブラウザの中だけで動きます。画像はどこにも送信されません。

## 使い方

`index.html` をブラウザで開くだけです。ビルドもサーバーも要りません。

```
D:\WebDev\QRCodeAnalyzer\index.html   ← ダブルクリック
```

GitHub Pages に置く場合は、リポジトリをそのまま公開設定にすれば動きます（追加設定なし）。

動作確認用のQR画像が `samples/` にあります。まとめてドラッグ＆ドロップしてみてください。
`09-three-in-one.png` は1枚に3つ入っているので、複数検出の確認に使えます。

## 表示される内容

一覧では、画像名・種別・中身・バージョン・誤り訂正レベル・マスクパターン・エンコードモードが並びます。
中身の種別は URL / テキスト / Wi-Fi設定 / 連絡先 / メール / 電話番号 / SMS / 位置情報 を見分けます。
リンクにするのは `http` と `https` だけです（`javascript:` などは文字列として表示するだけ）。

行を選ぶと出る詳細パネルでは、次のものが見られます。

- 元画像と、検出したシンボルの枠
- **モジュールの領域を色分けした図** — ファインダパターン / 分離パターン / タイミングパターン /
  位置合わせパターン / フォーマット情報 / バージョン情報 / 固定の暗モジュール /
  データコードワード / 誤り訂正コードワード / 残余ビット
- マスにポインタを重ねると「行12 列8・黒／データコードワード 第37コードワードの3ビット目 …」のような説明
- 「マスクを解除して表示」の切り替え（規則的な白黒反転を外した、生のビット配置が見えます）
- コードワードの内訳（データ何個・誤り訂正何個・ブロック数・残余ビット数）

## 仕組み

画像処理（二値化・ファインダパターン検出・傾き補正・誤り訂正）は
[jsQR](https://github.com/cozmo/jsQR)（Apache-2.0）に任せ、`js/vendor/` に同梱しています。
そのうえで、jsQRが返す**シンボル外周の四隅**を使って自前でモジュール格子を取り直し、
規格で位置が決まっている領域を読み解いています。

```
画像 ─→ [jsQR] 検出・読み取り ─→ 文字列 + 四隅の座標 + バージョン
                                     │
                                     ├─→ [grid]     射影変換でモジュール格子をサンプリング
                                     ├─→ [analyze]  フォーマット情報をBCH復号（誤り訂正レベル・マスク）
                                     │              バージョン情報を復号、マスクを解除してコードワードへ
                                     ├─→ [layout]   各モジュールが何の領域かを算出
                                     └─→ [payload]  中身がURLかWi-Fi設定かなどを判定
```

複数QRへの対応: jsQRは1回に1つしか返さないうえ、1枚に複数写っているとファインダパターンを
取り違えて1つも返さないことがあります。そのため正方形の窓を半分ずつ重ねながらずらして走査し、
見つけたシンボルは塗り潰してから次を探す、という方法をとっています。

### ファイル構成

| ファイル | 役割 |
| --- | --- |
| `js/tables.js` | バージョンごとの符号語数・位置合わせパターン座標（`tools/gen-tables.js` が生成） |
| `js/format.js` | フォーマット情報・バージョン情報のBCH復号、マスク関数 |
| `js/layout.js` | 各モジュールの領域判定、データ読み出し順 |
| `js/codewords.js` | データ／誤り訂正コードワードの境目と残余ビット |
| `js/grid.js` | 射影変換とモジュール格子のサンプリング、大津の二値化 |
| `js/detect.js` | jsQRを使った検出、複数QRの窓走査 |
| `js/analyze.js` | 格子からパラメータを読み解く。白黒反転の判定も |
| `js/payload.js` | 中身の種別判定 |
| `js/pipeline.js` | 上記をつないで、画像1枚の解析結果にする |
| `js/describe.js` | 画面に出す日本語の文言 |
| `js/ui.js` / `js/main.js` | 描画とファイル入力 |

`index.html` は素の `<script>` タグで読み込んでいるので、`file://` から直接開けます。
読み込み順に依存があるため、ファイルを増やすときは `index.html` の並びに注意してください。

## 開発

```sh
npm install       # 開発用の依存だけ（アプリ本体に実行時依存はありません）
npm test          # 全テスト
npm run samples   # samples/ の画像を作り直す
npm run tables    # js/tables.js を作り直す
```

テストは `qrcode` パッケージで**答えの分かっているQR**を生成し、それを画像に描いてから
解析し直して突き合わせています。誤り訂正レベルとマスクパターンは生成時の値と一致するか、
データ領域のモジュール数は規格の符号語数と一致するか、といった形で検証しています。
`test/browser-load.test.js` は `index.html` と同じ順でスクリプトを読み込んでブラウザ側の経路を、
`test/ui.test.js` は jsdom で画面描画を確認します。

## 制限

- 写真のような歪み・影の強い画像はjsQRの検出能力に依存します。まずは正面から撮ったもの、
  スクリーンショット、PDFからの切り出しを想定しています。
- 長辺2400ピクセルを超える画像は、解析前に縮小します。
- 1枚あたり最大20個まで、jsQRの呼び出しは最大400回までで打ち切ります。
- 1枚に複数写っている場合、窓をずらして探す都合上、**短辺のおよそ1/8より小さいQRは
  見つけられないことがあります**（1つだけ写っている画像なら、この制限はかかりません）。
- 誤り訂正で実際に何バイト直ったかは表示しません（jsQRが内部で訂正しており、
  その情報を外に出さないため）。表示しているのはフォーマット情報の訂正ビット数だけです。
